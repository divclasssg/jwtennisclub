# 재무 중심 메인 대시보드 콘텐츠 설계

## 목표

메인 대시보드를 클럽 운영 전반을 빠르게 확인하는 첫 화면으로 다시 설계한다. 화면의 중심은 재무이며, 회원 정보는 클럽 규모를 이해하는 데 필요한 최소 요약만 제공한다.

대시보드는 페이지를 열거나 새로고침한 시점의 최신 원본 데이터를 사용한다. 화면을 열어 둔 동안 자동 갱신하는 실시간 구독은 사용하지 않는다.

## 제품 원칙

- 정보 우선순위는 클럽 요약, 이번 달 재무, 재무 추이, 최근 최종 마감 순서다.
- 재무는 회원보다 강하게 표현한다.
- 이번 달 미마감 값과 최종 마감된 확정값을 명확히 구분한다.
- 그래프는 흐름과 누적 결과를 서로 다른 두 그래프로 표현한다.
- 중간 결산은 원본을 잠그지 않는 공유용 기록이므로 추세 기준값으로 사용하지 않는다.
- 데이터가 없거나 계산할 수 없는 상태를 `0`으로 바꾸지 않는다.
- 대시보드에서 정모, 일반 일정과 상시 작업 대기 목록을 제공하지 않는다.

## 정보 구조

### 1. 클럽 요약

상단은 회원 요약과 현재 장부 잔액을 간단히 보여준다.

회원 요약의 대표값은 현재 활동 회원 수다. 다음 값을 작은 보조 정보로 표시한다.

- 활동 예정 회원 수
- 휴회 회원 수
- 이번 달 신규 회원 수
- 이번 달 휴회 전환 회원 수
- 이번 달 탈퇴 회원 수

회원별 목록, 이름, 연락처와 회원 처리 작업은 표시하지 않는다.

재무 요약의 대표값은 현재 장부 잔액이다. 미마감 상태의 현재 장부 잔액은 다음 계산 결과다.

```text
최근 최종 마감 기말 장부 잔액
+ 이번 달 실제 회비 수납액
- 이번 달 운영 지출
```

실제 회비 수납액에는 조정 수납액이 반영된 기존 결산 계산 계약을 그대로 사용한다. 이번 달이 최종 마감 전이면 `최종 마감 전 변동 가능`을 표시한다. 이번 달이 최종 마감되었으면 확정값으로 표시하고 변동 가능 안내를 제거한다.

### 2. 이번 달 재무 현황

이번 달 원본 데이터의 최신 상태를 다음 항목으로 보여준다.

- 총 청구액
- 실제 회비 수납액
- 운영 지출
- 당월 귀속 수지
- 완납 회원 수 / 회비 대상 회원 수
- 미납 회원 수
- 미납액
- 결산 상태

결산 상태는 미결산, 최근 중간 결산 유형·버전 또는 최종 마감 유형·버전을 구분한다. 사용자는 이 영역에서 해당 월의 결산 화면으로 이동할 수 있다.

납부율 백분율은 핵심 지표로 만들지 않는다. 부분 납부가 존재하므로 `완납 18 / 20명`처럼 검증 가능한 원자료에 가까운 표현을 사용한다.

### 3. 재무 추이

재무 추이는 서로 다른 목적을 가진 그래프 두 개로 구성한다.

#### 월별 수납·지출

- 그래프 유형: 그룹 막대그래프
- 수납: 실제 회비 수납액
- 지출: 운영 지출
- 범위: 최근 6개월

#### 장부 잔액 추이

- 그래프 유형: 선그래프
- 과거 최종 마감 월: 확정 기말 장부 잔액
- 이번 달 미마감: 현재 예상 장부 잔액
- 범위: 최근 6개월

이번 달의 미확정 점은 확정된 과거 월과 다른 점 모양 또는 점선으로 표현하고 `변동 가능`을 표시한다. 데이터가 한 달뿐이어도 점과 막대 하나로 정상 렌더링한다.

수납·지출과 장부 잔액을 한 그래프에 결합하지 않는다. 규모가 다른 값이 서로를 작게 보이게 하거나 이중 축이 변화를 과장할 수 있기 때문이다. 데스크톱에서는 두 그래프를 나란히 놓고 모바일에서는 세로로 쌓는다.

### 4. 최근 최종 마감

가장 최근의 활성 최종 마감을 다음 정보로 요약한다.

- 대상 월
- 최종 마감 버전
- 기초 장부 잔액
- 기말 장부 잔액
- 실제 회비 수납액
- 운영 지출
- 당월 귀속 수지
- 마감일

결산 상세 화면과 해당 최종 마감 PDF로 이동하는 링크를 제공한다. 월초에 이번 달 거래가 거의 없더라도 최근 확정 재무 상태를 확인할 수 있게 하는 영역이다.

## 그래프 데이터 규칙

- 장부 시작 월인 2026년 7월 이전은 표시하지 않는다.
- 최종 마감된 과거 월은 해당 활성 최종 마감 스냅샷을 사용한다.
- 이번 달이 미마감이면 현재 원본 데이터 기반 결산 미리보기를 사용한다.
- 이번 달이 최종 마감되었으면 활성 최종 마감 스냅샷을 사용한다.
- 중간 결산 스냅샷은 두 그래프 모두에서 제외한다.
- 데이터가 없는 월은 0원으로 채우지 않고 간격으로 처리한다.
- 그래프는 최대 최근 6개월만 표시한다.

## 데이터 조회 계약

서버 컴포넌트는 인증된 Supabase 전용 RPC `get_dashboard_page()`를 한 번 호출한다. 여러 화면용 RPC를 순차 호출하지 않으며, 한 요청 안에서 회원과 재무 집계의 기준 시점을 일치시킨다.

RPC 응답은 다음 정보를 포함한다.

- 조회 기준 시각
- 회원 요약
- 이번 달 재무 미리보기 또는 활성 최종 마감 스냅샷
- 이번 달 결산 상태
- 최근 최종 마감
- 최근 6개월 수납·지출·장부 잔액 시계열
- 재무 계산 가능 여부와 계산 차단 사유

RPC는 활성 운영자만 호출할 수 있다. 응답에는 회원 이름, 회원번호, 연락처, 개인별 납부 내역, 영수증과 내부 메모를 포함하지 않는다.

현재 장부 잔액, 이번 달 재무와 그래프는 기존 월별 결산 계산식을 재구현하지 않고 동일한 데이터베이스 결산 계산 계약을 재사용한다. 최종 마감 이력은 `final` 유형만 조회하고, 최근 최종 마감은 활성 상태인 가장 늦은 월을 선택한다.

## 컴포넌트 경계

- `DashboardOverview`: 회원 요약과 현재 장부 잔액
- `CurrentMonthFinance`: 이번 달 핵심 수치와 결산 상태
- `MonthlyCashFlowChart`: 월별 실제 수납·운영 지출 막대그래프
- `LedgerBalanceChart`: 확정·현재 장부 잔액 선그래프
- `LatestFinalClosing`: 최근 최종 마감 요약과 이동 링크

RPC 응답은 별도의 Zod 파서에서 검증하고 화면 컴포넌트에는 검증된 애플리케이션 타입만 전달한다. 각 컴포넌트는 자신의 표시 책임만 가지며 데이터베이스 호출을 직접 수행하지 않는다.

## 그래프 구현과 접근성

새 차트 라이브러리는 추가하지 않는다. 최대 6개월 데이터에 맞는 작은 서버 렌더링 SVG 컴포넌트를 구현한다.

- SVG에 접근 가능한 제목과 설명을 제공한다.
- 그래프와 동일한 값을 읽을 수 있는 보조 수치 요약을 제공한다.
- 색상만으로 수납·지출 또는 확정·미확정 상태를 구분하지 않는다.
- 음수 잔액, 모든 값이 0인 경우와 한 개 데이터 점을 안전하게 스케일링한다.
- 그래프에 클라이언트 JavaScript와 애니메이션을 사용하지 않는다.
- 모바일 화면에서 가로 스크롤이 생기지 않게 한다.

## 예외 상태

- 거래가 0건이면 실제 `0원`으로 표시한다.
- 최근 최종 마감이 없으면 `아직 최종 마감된 결산이 없습니다`를 표시한다.
- 한 달치 그래프 데이터만 있어도 정상 상태로 표시한다.
- 데이터가 없는 과거 월은 0원으로 표현하지 않는다.
- 활동 시작 월 미확인 등으로 결산 계산이 불가능하면 재무 금액을 `0원`으로 표시하지 않고 `계산 대기`와 차단 사유를 표시한다.
- 재무 계산이 차단되어도 조회 가능한 회원 요약과 최근 최종 마감은 유지한다.
- RPC 자체가 실패하면 이전 값이나 임의의 0원을 표시하지 않고 대시보드 조회 오류를 표시한다.

## 구현 순서 의존성

대시보드 데이터 계약은 월별 중간 결산·최종 마감 설계의 결산 유형, 활성 최종 마감과 결산 이력을 소비한다. 따라서 `2026-07-31-interim-final-closing-design.md`의 데이터 계약을 먼저 구현하거나, 동일한 구현 작업에서 대시보드 RPC보다 선행해야 한다.

기존 내부 `settlement` 식별자는 배포 호환성을 위해 유지할 수 있지만 사용자 화면에는 `결산` 용어를 사용한다.

## 검증

### 데이터베이스

- 회원 상태와 이번 달 회원 변화 집계가 월 경계를 지킨다.
- 현재 장부 잔액과 이번 달 재무가 기존 결산 계산식과 일치한다.
- 과거 그래프 값은 활성 최종 마감 스냅샷만 사용한다.
- 중간 결산 스냅샷은 그래프에서 제외된다.
- 최근 최종 마감 선택과 6개월 범위가 정확하다.
- 비활성 또는 비인증 사용자의 RPC 실행을 거부한다.
- 응답 JSON에 개인정보와 개인별 납부 데이터가 포함되지 않는다.

### 파서와 컴포넌트

- 잘못된 월, 금액, 데이터 순서와 중복 월을 거부한다.
- 정상, 첫 장부 월, 최근 최종 마감 없음, 계산 대기와 조회 실패 상태를 검증한다.
- 단일 월, 0원, 음수 잔액과 누락 월 그래프를 검증한다.
- 미마감 현재 월과 최종 마감 월의 라벨과 시각 표현을 구분한다.
- 링크가 올바른 월과 최종 마감 스냅샷을 지정한다.

### 통합 검증

- 전체 테스트, lint, TypeScript 검사와 프로덕션 빌드를 통과한다.
- 인증된 운영자 브라우저에서 데스크톱과 모바일 대시보드를 확인한다.
- 그래프 레이블과 보조 수치가 실제 DB 집계와 일치하는지 대조한다.
- 데스크톱과 모바일에서 가로 넘침이 없고 그래프를 읽을 수 있는지 확인한다.

## 범위 제외

- 정모와 일반 일정 정보
- 상시 작업 대기 목록과 빠른 메뉴 카드
- 회원별 목록과 개인정보
- 납부율 백분율을 대표 지표로 사용
- 전월 대비 증감률과 예측 지표
- 임의의 클럽 운영 점수
- 지출 카테고리 전용 그래프
- 중간 결산 버전을 사용한 추세
- 자동 새로고침, Supabase Realtime 구독과 그래프 애니메이션
