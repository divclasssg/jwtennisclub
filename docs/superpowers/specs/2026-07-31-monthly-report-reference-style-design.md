# 월간 결산 PDF 장부형 디자인

## 목표

첨부된 `문서2.pdf`의 간결한 흑백 회계 보고서 스타일을 월간 결산 PDF에 적용한다. 기존 결산 스냅샷의 수치·유형·버전·처리 이력은 유지하고, 회원 공유용 문서의 개인정보 제외 원칙도 유지한다.

## 선택한 방향

현재 데이터를 축약하지 않고 장부형으로 재배치한다.

- A4 세로형과 넓은 여백
- 좌측 상단 클럽명, 보고서 제목, 결산 월
- 우측 상단 결산 구분·처리일·처리자와 PDF 생성일·생성자
- 본문을 `회원 현황`, `수입`, `지출`, `잔액`, `지출 상세` 순서로 구성
- 항목명은 좌측, 금액은 우측 정렬
- 소계와 최종 잔액 위에 얇은 구분선을 사용하고 합계는 굵게 표시
- 카드 배경·박스 테두리·회색 표 헤더를 제거하고 흑백 타이포그래피와 선만 사용
- 하단에 귀속월·사용일 기준과 개인정보 제외 안내를 유지

## 콘텐츠 매핑

### 회원 현황

- 월말 활동 회원
- 회비 부과 대상
- 완납 회원
- 미납 회원

### 수입

- 총 청구액
- 실제 회비 수납액
- 인정 납부액
- 조정 수납액: 0원이 아닐 때만 표시
- 미납액

수입 합계는 실제 회비 수납액을 사용한다. 총 청구액·인정 납부액·미납액은 수납 상태를 설명하는 보조 행이며 중복 합산하지 않는다.

### 지출

- 카테고리별 건수와 금액
- 운영 지출 합계

### 잔액

- 기초 장부 잔액
- 당월 귀속 수지
- 기말 장부 잔액
- 계산식 안내

### 지출 상세

- 사용일
- 카테고리
- 내용
- 금액

정상적인 월은 1페이지를 목표로 한다. 지출 행이 많으면 내용이 잘리거나 축소되지 않고 다음 페이지로 자연스럽게 이어진다.

## 개인정보 및 운영 규칙

- 개인 전화번호, 미납 회원명, 개별 납부 내역, 영수증, 내부 메모는 포함하지 않는다.
- 첨부본의 개인 연락처와 회칙 문구는 자동으로 복제하지 않는다.
- 데이터베이스, 결산 RPC, 스냅샷 형식과 다운로드 감사 기록은 변경하지 않는다.

## 구현 범위

- `MonthlyReportPdf.tsx`의 레이아웃과 스타일을 장부형으로 변경한다.
- 기존 `MonthlyReportData` 계약과 파일명 규칙은 유지한다.
- 대표 최종 마감 시안 PDF를 `output/pdf/`에 생성한다.
- 중간 결산과 재개된 최종 마감 라벨도 같은 레이아웃에서 검증한다.

## 검증

- 텍스트 추출로 모든 공개 결산 항목과 결산 유형·버전·시각이 유지되는지 확인
- PDF가 유효한 A4 문서인지 `pdfinfo`로 확인
- 150dpi PNG 렌더링으로 정렬·구분선·한글 글리프·잘림·겹침을 육안검사
- 대표 1페이지 문서와 지출 행이 많은 다중 페이지 문서를 자동 테스트
- 전체 테스트, ESLint, TypeScript와 프로덕션 빌드 실행

## 제외 범위

- 운영 배포
- 실제 운영 결산 PDF 다운로드 실행
- 연락처·회칙을 관리하는 설정 기능
- 데이터베이스 마이그레이션
